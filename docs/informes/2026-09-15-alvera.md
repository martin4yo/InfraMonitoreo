## 2. Escenario simulado

Pérdida total del servidor de producción. Recuperación en un servidor de recuperación **de otro proveedor**,
usando solo fuentes independientes del servidor perdido:

| Componente | Fuente usada |
|---|---|
| Base de datos | Respaldo continuo, **cifrado**, almacenado fuera del proveedor principal |
| Código | Repositorio versionado — **la misma versión que operaba en producción** |
| Configuración y credenciales | Custodia cifrada independiente de los servidores |
| Archivos adjuntos | Respaldo cifrado fuera del proveedor principal (cada 15 minutos, desde 2026-09-15) · copia secundaria diaria |

**El entorno productivo no se tocó** y el servicio no tuvo interrupción.

## 3. Protección de los datos durante la prueba

- Acceso al entorno de recuperación por HTTPS con certificado válido; servicios internos no expuestos.
- **Antes de iniciar la aplicación se desactivaron WhatsApp, correo y SMS** en la copia restaurada, para que
  ningún paciente recibiera mensajes originados en la prueba.
- La legibilidad de los datos cifrados se verificó **por conteo**, sin visualizar contenido.
- **El entorno se eliminó el mismo día**: base de datos, archivos, configuración y certificado.
